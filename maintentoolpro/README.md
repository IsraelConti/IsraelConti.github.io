# MaintenTool Pro · beta pública 0.6.0 (MMHI.TEC)

**Prueba web para PC y móvil:** https://israelconti.github.io/maintentoolpro/app/index.html

Esta edición incluye gestión local de equipos, órdenes, preventivos, almacén, averías, reincidencias, análisis, documentación, fotografías, QR e informes, con interfaz para ordenador y móvil.

**Limitaciones:** no hay sincronización automática entre dispositivos, multiusuario, pagos, suscripción ni servicio de atención contratado. Los datos se guardan en el navegador; exporta JSON regularmente. No usar en producción ni para información sensible. No es una descarga EXE. Para consultas comerciales: contini1976@gmail.com.
